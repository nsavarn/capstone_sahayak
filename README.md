# Sahayak Health AI — Capstone B

Safety-first multi-agent triage decision-support prototype for community health workers.

## Canonical submission artifacts

- `adk_foundations.ipynb`
- `data_understanding_and_baseline.ipynb`
- `agent_pipeline_development.ipynb`
- `agent_evaluation_and_optimisation.ipynb`
- `sahayak_starter.py`
- `final_report.pdf`

## Execution status

The notebooks must be executed in order in the intended Google Colab / ADK environment before the results are treated as final. Regenerate the report from the final notebook outputs. Do not represent offline fallback execution as live model inference or full-dataset evaluation.

## Safety and scope

This is an educational decision-support prototype, not a diagnosis tool or substitute for qualified clinical judgement. ER recall, under-triage, and ER-to-WAIT errors are explicit evaluation concerns.

## Colab

The project can be run with the [Google Colab CLI](https://github.com/googlecolab/google-colab-cli) after authenticating and configuring a runtime. Retain execution logs and executed notebook outputs as evaluation evidence.
